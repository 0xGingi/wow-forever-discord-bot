A little more UWU

The UWUCREW Sync app.

Installs the guild addon and keeps it updated, syncs your characters to our Discord every time you log out, and shows the crew’s raids, roster and progress. It updates itself, too.

WindowsMac (Apple Silicon)Mac (Intel)Addon only & source
How to set it up
  1. Install the app. Windows: if SmartScreen warns, click More info → Run anyway. Mac: open the DMG and drag the app into Applications. Playing on Linux through Wine or Proton? Install the Windows app into the same prefix as the game.
  2. Open it: it finds your WoW:Forever folder and installs the addon for you.
  3. Run /sync link in our Discord and paste the code into the app (Settings → Discord link).
  4. Play! It syncs each time you log out or /reload, and keeps running from the tray.
